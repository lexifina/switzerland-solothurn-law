# § 8 Erfahrungsnote
1 Die Erfahrungsnote entspricht dem auf eine halbe oder ganze Note gerundeten arithmetischen Mittel aller im Fach Allgemeinbildung erteilten Semesterzeugnisnoten.
2 Wiederholt eine lernende Person im Fach Allgemeinbildung das letzte Jahr der beruflichen Grundbildung, so zählen für die Erfahrungsnote nur die in diesem Schuljahr erteilten Noten.
